# Tempo Push — downloads

Installers for **Tempo Push**, the Windows app for musicians who play to loops.

- Play any loop at any speed, without changing its key.
- Split a song into music and voices — for choirs, worship teams and bands.

**[Download the latest version](https://github.com/Jazital/tempo-push-downloads/releases/latest)**

## Installing

1. Download `Tempo Push Setup <version>.exe` from the latest release.
2. Run it. Windows may warn about an unrecognised publisher — choose **More info**, then **Run anyway**.
3. Already have Tempo Push? Close it first and install over the top. Your tracks, playlist, history and settings are kept.

An `.msi` is published alongside the `.exe` for anyone deploying it across several machines.

## Requirements

Windows 10 or 11, 64-bit. Everything runs on your own computer — playing, splitting and exporting all work with no internet connection.
